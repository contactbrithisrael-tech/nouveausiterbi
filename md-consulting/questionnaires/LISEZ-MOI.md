# Questionnaires

Onze outils, transcrits des documents MD Consulting fournis. Le format est
décrit dans `docs/questionnaires.md`, et les effectifs sont vérifiés par
`tests/test_questionnaires.py` : une transcription abîmée fait échouer la suite.

Rien n'a été inventé, reformulé ni complété. Là où le document source est
incomplet — le rattachement des items aux thématiques du test de création
d'entreprise —, le champ reste vide et le calcul correspondant n'est pas fait.

Ajouter un outil : déposer un fichier JSON ici. Aucune modification du code
ni de la base n'est nécessaire.
